Antes de ejecutar el backend debes crear un entorno virtual y activarlo.

1. Abre la terminal y cambia a la carpeta del backend:
   cd backend

2. Crea el entorno virtual:
   python -m venv .venv

3. Activa el entorno virtual:
   .\.venv\Scripts\activate

4. Instala las dependencias de Python:
   pip install fastapi uvicorn sqlalchemy psycopg2-binary python-jose passlib[bcrypt]

5. Configura la base de datos PostgreSQL:
   - Asegurate de tener un servidor de postgres corriendo.
   - Crea la base de datos si no existe:
     createdb sise
   - Ajusta la URL de conexion en backend/database.py si es necesario.

6. Ejecuta el backend:
   uvicorn main:app --reload

7. Abre la documentacion interactiva:
   http://127.0.0.1:8000/docs

Notas:
- Mantén activo el entorno virtual mientras trabajas en el backend.
- Si usas pgadmin, verifica usuario y contraseña de postgres.
- Si necesitas resetear datos, puedes truncar tablas con cuidado.
- El archivo seed.py crea datos iniciales para usuarios y registros basicos.


para modificar la contrasena de un usuario de postgres puedes usar:
ALTER USER postgres WITH PASSWORD 'postgres';

Para borrar datos de las tablas de los registros que realiza el seed.py
TRUNCATE TABLE usuarios CASCADE;
